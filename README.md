# Country_Bean
Project Title: Image-Based Detection of Yellow Mosaic Virus in Country Bean Leaf Using Hybrid Deep Learning Approaches
This repository features an advanced hybrid architecture leveraging EfficientNetV2-S and ViT-S/16 with an attention-based fusion mechanism for high-accuracy bean disease diagnosis. It offers a complete end-to-end framework complete with cross-validation, ablation experiments, FLOPs/parameter profiling, and batch Grad-CAM visual explanations.
